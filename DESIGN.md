# Bulls and Cows — DESIGN.md

## 1. Структуры данных и алгоритмы

### Состояние игры

Состояние игры представлено объектом `Game` (`src/types/types.ts`):

- `secret` — загаданная последовательность цифр в виде строки, поэтому сохраняются лидирующие нули;
- `config` — длина секрета и основание системы счисления;
- `status` и `isNewGame` — статус раунда;
- `history` — массив записей о попытках;
- `totalTime` — поле для времени игры.

`makeGuess` (`src/game/core/makeGuess.ts`) при корректной попытке создаёт новую запись `GuessHistory` с номером попытки, временем, самой попыткой и результатом. Затем возвращает новое состояние игры с новым массивом истории: `[...game.history, entry]`. Исходное состояние не изменяется. Некорректная попытка не добавляется в историю.

### `generateSecret(length, base, random)`

Функция (`src/game/core/generateSecret.ts`) выбирает символы из алфавита `0123456789abcdef`, используя переданный генератор случайных чисел. Если символ уже выбран, функция выбирает снова; генерация завершается, когда набрано `length` уникальных символов. Секрет возвращается строкой, поэтому может начинаться с нуля. Передача `random` позволяет использовать детерминированную последовательность в тестах.

### `evaluateGuess(secret, guess)`

Функция (`src/game/core/evaluateGuess.ts`) приводит обе строки к нижнему регистру. Bulls подсчитываются через `reduce` сравнением символов на одинаковых позициях. Для подсчёта общего числа совпавших символов используется `filter`: повторяющиеся символы в попытке не учитываются повторно. Cows вычисляются как общее число совпадений минус bulls.

### `isValidGuess(guess, length, base)`

Функция (`src/game/core/isValidGuess.ts`) проверяет, что попытка задана, её длина совпадает с требуемой, все символы допустимы для выбранного основания, а символы не повторяются. Допустимость каждого символа проверяет функция, созданная через `createDigitValidator(base)`.

### `createDigitValidator(base)`

Функция (`src/game/core/createDigitValidator.ts`) каррирует проверку: по основанию системы счисления возвращает предикат для проверки отдельного символа. Для сравнения символ приводится к нижнему регистру. Валидатор используется в `isValidGuess`.

### `countPossibleSecrets(length, base)`

Функция (`src/game/core/countPossibleSecrets.ts`) рекурсивно вычисляет количество секретов без повторяющихся цифр:
`count(length, base) = base * count(length - 1, base - 1)`.
Базовый случай — `length === 0`, результат равен `1`. Результаты промежуточных вычислений сохраняются в `Map` по паре `length-base` и используются при повторных вызовах.

## 2. Сложность

Здесь `n` — количество цифр в числе.

- **`generateSecret` — O(n²) без повторных выпадений:** функция добавляет цифры по одной и каждый раз копирует уже собранный набор. Если выпадает уже выбранная цифра, функция пробует снова, и генерация занимает больше времени.
- **`evaluateGuess` — O(n²):** функция проверяет цифры попытки и ищет их в секретном числе. Для каждой цифры может понадобиться снова просмотреть всё число.
- **`isValidGuess` — O(n):** функция проверяет каждую цифру один раз. Список допустимых цифр небольшой и ограничен, поэтому с каждой цифрой можно работать за постоянное время.
- **`countPossibleSecrets` — O(n):** функция рекурсивно уменьшает длину на 1, пока не дойдёт до 0. Поэтому при длине `n` ей нужно примерно `n` вызовов. Если результат уже сохранён в кэше, его можно вернуть сразу — это O(1).

## 3. Принципы чистого кода

- **Иммутабельность:** `makeGuess` (`src/game/core/makeGuess.ts`) создаёт новое состояние и новый массив истории, не изменяя исходный объект.
- **Функции высшего порядка:** `evaluateGuess` (`src/game/core/evaluateGuess.ts`) использует `reduce` и `filter` для вычисления результата попытки.
- **Каррирование и повторное использование:** `createDigitValidator` (`src/game/core/createDigitValidator.ts`) возвращает функцию-предикат; сейчас она используется при проверке попытки в `isValidGuess` (`src/game/core/isValidGuess.ts`). Её использование для фильтрации ввода в интерфейсе, как требует задание, пока не реализовано.
- **Рекурсия и мемоизация:** `countPossibleSecrets` (`src/game/core/countPossibleSecrets.ts`) использует рекурсивную формулу и кэш `Map`.
- **Тестируемость случайной генерации:** `generateSecret` (`src/game/core/generateSecret.ts`) принимает источник случайности параметром, поэтому тесты могут передавать детерминированную функцию вместо `Math.random`.
